# 穿搭创作使用指南与动态导航验收记录

## 实施内容

- 后台新增 `/creation/guide` 使用指南，并设为“穿搭创作”默认页。
- 指南区分用户私人艺术创作和官方公开展示素材，提供四个管理页面入口、两条操作流程及常见问题。官方素材入口按 `closet:showcase:read` 权限禁用或开放。
- 动态菜单在“穿搭创作”下新增 `closet-creation-guide`，排序为 0、权限为 `closet:creation:read`；既有“鱼搭业务 → 官方素材”菜单保持原位置。
- 为穿搭创作菜单和四个子页面补齐离线 Remix 图标。

## 验收边界

- 指南为静态说明，只使用当前权限和前端路由；未增加业务 API，也未发起模型调用。
- 后端修改仅包括管理导航初始化与合法组件键白名单。
- 本记录不代表浏览器视觉验收或运行服务更新；由主代理按任务单完成。
